Namespace ASE_Assignment

Classes

AppArray

Restrictions on the custom array on maximum number of arrays and their dimensions. Inherits all the essentials from the BOOSE.Array class.

AppCanvas

Implementation of Canvas for BOOSE drawing system. Implements the ICanvas interface to help provide the drawing functionality.

AppCommandFactory

A default (factory) class for creating specific commands. Extends the base BOOSE.CommandFactory to include custom commands.

AppFor

Represents a custom implementation of the BOOSE.For class for creating and executing a for loop. Allows for a loop with customisable start, end, and step values, along with a block of code to execute in each iteration.

AppIf

Represents a custom implementation of the BOOSE.If class for handling conditional statements. Inherits from BOOSE.If and allows for custom restrictions to be applied.

AppMethod

Represents a custom implementation of the BOOSE.Method class. This class defines a method with a name, return type, and parameters, and enforces a restriction to allow only one method definition.

AppReal

Represents the implementation of the real functionality of the application. Inherits from the BOOSE.Real base class.

AppRect

Represents a rectangle that can be drawn on a canvas, with an optional fill property. Inherits from the BOOSE.Rect class and implements the BOOSE.ICommand interface.

AppStoredProgram

Represents an extended version of the BOOSE.StoredProgram class with additional functionalities. Manages stored commands and executes them with added error handling and restrictions.

AppTriangle

Represents a command to draw a triangle on the canvas.

AppWrite

Represents a command to write text on the canvas.

Clear

Represents a command to clear the canvas.
